# 정육단 창업 문의 페이지

정육단 프랜차이즈 창업 상담용 원페이지 랜딩 사이트입니다. 빌드 도구 없이 순수 HTML/CSS/JS로만 만들어져 있습니다.

## 폴더 구조

```
├── index.html      페이지 전체 구조
├── css/style.css   스타일 (블랙 & 딥레드 톤, 반응형)
├── js/main.js      스크롤 등장 효과, 카운터, 폼 검증
└── vercel.json     Vercel 배포 설정
```

## 페이지 구성

1. 히어로 — "로스율 0%, 뜯어서 서빙하는 고깃집" + 대표 영상
2. 브랜드 — 올바른 고기를 믿고 사는 시스템, 패밀리 프랜차이즈, 100년 가게
3. 왜 정육단인가 — 원팩 시스템 / 독점 메뉴 / 소주 1,000원 마케팅
4. 운영 시스템 — HACCP 공장, 커팅 설비, 물류, 발주 가이드
5. 메뉴 경쟁력 — 오징어 꽃삼겹, 숙성 삼겹살, 진생베리 숙성, 사이드
6. 수익 구조 — 본점 매출·순마진율·객단가 + 인싸맨 영상
7. 상권 정책 — 1구 1점, 인재상, 인테리어 콘셉트
8. 창업 비용 / 가맹 절차 / FAQ / 창업 상담 폼

## 로컬에서 확인하기

```bash
python -m http.server 8756
```

브라우저에서 http://localhost:8756 으로 접속합니다.

## 배포

Vercel에 GitHub 저장소가 연결되어 있으며, `main` 브랜치에 push하면 자동으로 배포됩니다.

## 오픈 전 교체가 필요한 항목

- **창업 비용표** — 현재 금액은 예시입니다. 정보공개서 기준 실제 금액으로 교체해야 합니다.
- **연락처** — 대표전화 `1600-0000`이 `index.html`(헤더·문의 섹션·하단 CTA)에 들어 있습니다.
- **사업자 정보** — 푸터의 상호, 대표자명, 사업자등록번호, 주소, 이메일.
- **문의 폼 전송** — 현재는 화면에 완료 메시지만 표시되고 실제로 전송되지 않습니다. `js/main.js`의 `TODO` 주석 위치에 백엔드 API 또는 폼 서비스(Formspree, Google Forms 등) 연동이 필요합니다.
- **이미지** — 현재 사진 없이 그라데이션과 영상으로만 구성되어 있습니다. 매장·메뉴 사진 추가를 권장합니다.

### 매출 표기 관련 주의

수익 구조 섹션의 수치(본점 월매출 1억~1.3억원, 순마진율 30~32%, 객단가 8만원선)는 **본사 직영 본점 기준**으로 표기하고, 가맹점 매출을 보장하지 않는다는 문구를 함께 넣어두었습니다. 가맹사업법상 예상매출액 관련 정보는 서면(예상매출액 산정서) 제공 의무가 있으므로, 홍보를 본격적으로 시작하기 전 법무 검토를 권장합니다.
