# 정육단 창업 문의 페이지

정육단 프랜차이즈 창업 상담용 원페이지 랜딩 사이트입니다. 빌드 도구 없이 순수 HTML/CSS/JS로만 만들어져 있습니다.

## 폴더 구조

```
├── index.html      페이지 전체 구조
├── css/style.css   스타일 (블랙 & 딥레드 톤, 반응형)
├── js/main.js      스크롤 애니메이션, 폼 검증
└── vercel.json     Vercel 배포 설정
```

## 로컬에서 확인하기

```bash
python -m http.server 8756
```

브라우저에서 http://localhost:8756 으로 접속합니다.

## 배포

Vercel에 연결되어 있으며, `main` 브랜치에 push하면 자동으로 배포됩니다.

## 오픈 전 교체가 필요한 항목

- **매출·가맹점 수 등 모든 수치** — 현재는 예시 값입니다. 가맹사업법상 허위·과장 정보 제공은 제재 대상이므로 반드시 정보공개서 기준 실제 데이터로 교체해야 합니다.
- **연락처** — 대표전화 `1600-0000`이 `index.html`과 `js/main.js`에 들어 있습니다.
- **사업자 정보** — 푸터의 상호, 대표자명, 사업자등록번호, 주소, 이메일.
- **문의 폼 전송** — 현재는 화면에 완료 메시지만 표시되고 실제로 전송되지 않습니다. `js/main.js`의 `TODO` 주석 위치에 백엔드 API 또는 폼 서비스(Formspree, Google Forms 등) 연동이 필요합니다.
- **이미지** — 현재 사진 없이 그라데이션으로만 구성되어 있습니다.
